<Warning>
**Deprecation notice — these endpoints are slated for removal.**

The Service Provider API (`/service-providers/*`) is deprecated. All customers should move to the [Network Partner API](/api-reference/network-partners) as soon as possible, and no new integration should be built against these endpoints.

Follow the [Service Provider → Network Partner migration guide](/docs/stablecoins/white-label-api-integration/migration-service-provider-to-network-partner) — it maps every legacy call to its replacement.
</Warning>

The Service Providers API reference is versioned.

Use the version selector in the header to choose the API date you want, then open **Service Providers** in the API Reference sidebar to browse endpoints.

Deep links under `/api-reference/service-providers/...` stay stable while the selected API version changes the underlying schema and examples.
