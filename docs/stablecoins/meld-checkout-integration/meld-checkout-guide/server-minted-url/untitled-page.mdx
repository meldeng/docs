# Meld Checkout Integration Quickstart

**Time required:** 5 minutes. **Difficulty:** No coding required

## Before you begin

- Access to the Meld dashboard (sandbox and production are separate)
- A page in your app where you can render a link or trigger a redirect

<Note>
  **Sandbox vs production:** Each environment has its own Meld Checkout URL. Sandbox URLs only work with test data; production URLs handle real money. Always finish testing in sandbox first.
</Note>

## Step 1: Get Your Meld Checkout URL

<Steps>
  <Step title="Open the dashboard">
    Check your email for the Meld dashboard invitation, click the link, and log in at [https://dashboard.meld.io](https://dashboard.meld.io).
  </Step>
  <Step title="Generate Meld Checkout URL">
    Go to **Developer → API Keys**. Press the **Generate Meld Checkout URL** button.

    <Note>
      **You will need to mint the URL per customer's visit in full integration. Generate Meld Checkout URL button serves integration testing purposes only.**
    </Note>
  </Step>
</Steps>

## Step 2: Send the customer to the URL

Mint on demand — when the customer clicks your buy button — then redirect, open a tab, or embed:

<CodeGroup>

```javascript Redirect
window.location.href = 'https://meldcrypto.com?wt=3Qm9ZP2r8yVtNn6bK1sWfDcXhLqA7uJeR4gTmB5oYvS';
```

```javascript New window
window.open(widgetUrl, 'meld-checkout', 'width=450,height=790,scrollbars=yes,resizable=yes');
```

```html Iframe
<iframe
  src="https://meldcrypto.com?wt=3Qm9ZP2r8yVtNn6bK1sWfDcXhLqA7uJeR4gTmB5oYvS"
  width="450"
  height="790"
  frameborder="0"
  allow="camera; microphone; payment">
</iframe>
```

</CodeGroup>

For iframes, keep a minimum width of 450px and height of 790px, and include the `camera`, `microphone`, and `payment` permissions so KYC and payment flows work.

<Note>
  **How long is the URL good for?** A minted URL keeps working until Meld's retention sweep removes its stored configuration — 30 days after minting by default.
</Note>

## Step 4: Test in sandbox

<Steps>
  <Step title="Open the minted URL">
    Paste it into your browser. The checkout should load with no values prefilled — the customer picks everything.
  </Step>
  <Step title="Complete a test transaction">
    Follow the [sandbox test credentials](/docs/stablecoins/sandbox-guide/test).
  </Step>
  <Step title="Verify in the dashboard">
    Check the **Transactions** tab for the test transaction.
  </Step>
</Steps>

## Step 5: Go live

<Steps>
  <Step title="Swap keys and base URL">
    Use your production secret and public keys against `https://api.meld.io`.
  </Step>
  <Step title="Test with a small real transaction">
    Confirm the full flow end to end before directing traffic.
  </Step>
  <Step title="Send customers to the minted URL">
    Mint per checkout from your backend and redirect.
  </Step>
</Steps>

✅ **Integration complete.** Customers can now buy and sell digital assets through Meld Checkout.
