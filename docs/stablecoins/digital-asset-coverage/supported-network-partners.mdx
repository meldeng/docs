<Tip>
  Network Partner API access

  The data on supported crypto currencies, countries, fiat currencies, and payment methods is also available via the Network Partner [endpoints](https://docs.meld.io/api-reference/network-partners/supported/list-supported-countries).

  The Network Partner Properties endpoints are a powerful and normalized way for developers to assess which service providers provide the services desired based on the token to be purchased, available payment methods, and supported countries and currencies.
</Tip>
