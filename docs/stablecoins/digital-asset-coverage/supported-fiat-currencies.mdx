Service Providers accessed through Meld support a wide variety of fiat currencies. You can find a list of supported fiat currencies for onramps and offramps below:

[Supported Fiat Currencies for Onramps](#supported-fiat-currencies-for-onramps)<br />[Supported Fiat Currencies for Offramps](#supported-fiat-currencies-for-offramps)

The `GET /network-partner/supported/currencies?category={CATEGORY}&country={c}&type=FIAT` endpoint can also be used to obtain this information.

<Warning>
`GET /service-providers/properties/fiat-currencies` is **deprecated** and slated for removal. Use `GET /network-partner/supported/currencies?category={CATEGORY}&country={c}&type=FIAT` instead — see the [migration guide](/docs/stablecoins/white-label-api-integration/migration-service-provider-to-network-partner). Migrate as soon as you can.
</Warning>

<Note>
  Interacting with our Coverage docs

  Please note that all coverage sheets are set to 'view only' access. To filter the data and use these sheets more easily, please create a local filter.

  To create a local filter, click on 'Data' \> 'Filter views' \> 'Create new temporary filter view'. Now, you can interact with Meld's coverage documents with ease!
</Note>
